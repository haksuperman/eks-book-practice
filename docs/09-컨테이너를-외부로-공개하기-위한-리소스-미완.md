# 09. 컨테이너를 외부로 공개하기 위한 리소스 (미완)

> 마지막 편집: 2026-09-26T11:05:29.974Z

## 1. 파드를 서비스로 묶기
### 1.1. 예제 애플리케이션의 서비스 리소스
```yaml
apiVersion: 1                   # 1.
kind: Service                   # 2.
metadata:
  name: backend-app-service     # 3.
spec:
  type: LoadBalancer            # 4.
  selector:
    app: backend-app            # 5.
  ports:
  - protocol: TCP               # 6.
    port: 8080                  # 7.
    targetPort: 8080            # 8.
```
1. `apiVersion: 1` : 정의한 서비스 리소스가 따르는 버전이다.
2. `kind: LoadBalancer` : 이 매니페스트가 서비스 리소스를 정의한다는 것을 나타낸다.
3. `name: backend-app-service` : 서비스 리소스의 이름이며, DNS 이름으로 등록되어 클러스터 내부에서 참조할 수 있게 된다.
4. `type: LoadBalancer` : 서비스 종류로, 서비스로 동작하는 로드밸런서가 생성되고 로드밸런서를 통한 접속이 가능하다.
5. `app: backend-app` : 이 서비스가 대상으로 하는 파드를 선택하기 위한 셀렉터 정의이다.
6. `protocol: TCP` : 이 서비스에 접속하기 위한 프로토콜이다.
7. `port: 8080` : 이 서비스에 접속하기 위한 포트 번호이다.
8. `targetPort: 8080` : 파드의 8080 포트에 매핑한다는 의미이다.
